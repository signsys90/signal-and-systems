## What changed

Between the morning sync and the evening of 31 Oct, Upfit Studio went from version 0.5.2 to 0.8.10. The biggest addition is the Whelen Command CANport setup: eight vehicle signals the CanTrol reads from the OBD-II port through the Whelen CC5K1 kit.

| CANport | Same table on the F-150 output plan | [Output plan](/projects/f150-upfit/cantrol-output-plan/#canport-vehicle-inputs) |

## One source for every CANport table

The CANport tables on both pages are drawn from one file, `src/data/f150-upfit/canport.json`, written by `scripts/sync_upfit_studio.py` from the app's own plan. A change to the CANport setup is re-synced in one step and shows up on both pages.

## Status

Seven of the eight CAN inputs are keyed into my Command file "-3" (brake pop first pass only). Shift out of Park is not programmed yet. Nothing has been bench-tested on the module or truck.

## Later: Command file "-4"

A newer Command file, "-4", was saved the same evening. It has the same Command version, names and eight CAN signals as "-3", which still match the plan. About 50 bytes of the undecoded programming logic changed. What changed isn't confirmed yet, so CAN 6 (Park) and the brake pop timer stay marked as not programmed.
