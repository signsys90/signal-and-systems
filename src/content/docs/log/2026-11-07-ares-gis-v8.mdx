## What changed

The ARES Duval GIS Command Dashboard moved from v7.1.5 to v8.0.0. The rebuild adds a tactical command interface (HUD, command palette, night-vision mode, mobile command mode), a Live Wx drawer with 17 public weather, flood, outage and traffic overlays, and a Net Log that produces ICS-309 communications logs. It also fixes nine bugs, including a mobile crash and an XSS hole in address search, and hardens auth, headers and data writes.

## Status

- 16 unit tests, the API smoke test and 22 browser UI tests pass (Linux cloud sandbox, 7 Nov 2026).
- **Live overlays and map tiles have not yet been seen loading** on a networked machine.
- **v8.0.1 is deployed to Render** (2026-11-07, commit `c29e29e`). `/healthz` reports 8.0.1, `/api/health` is ok, and the dashboard requires a login.
- The live service is on Render's free plan with no persistent disk, so data entered there is lost on restart or redeploy.
