The examples on this page use placeholder values to show layout only. They are not real specs.

Import components at the top of an `.mdx` page with a relative path, for example `import Callout from '../../../../components/Callout.astro';` from a project page.

## 1. Project header card

`<ProjectHeader />` reads `summary`, `status`, `category`, `started` and `updated` from the page frontmatter. Pass `hero={image}` and `heroAlt="..."` for a hero photo. See any [project page](/projects/) for a live example.

## 8. Code block

Starlight's built-in code blocks include a copy button. Add a title to label the language or file:

```python title="example.py"
print("Signal & Systems")
```

## 9. Photo gallery and before/after slider

`<Gallery photos={[{ src: photo, alt: '...', caption: '...' }]} />` and `<BeforeAfter before={a} after={b} alt="..." />`. Import photos from `src/assets/` so Astro optimizes them. Strip EXIF/GPS data and blur plates and house numbers first.
