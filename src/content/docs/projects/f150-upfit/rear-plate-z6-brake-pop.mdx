## Goal

Two small warning heads at the rear plate that flash amber/clear with the rest of the system, and switch to steady red whenever the brake pedal is pressed. The brake signal comes from the truck's data bus, so no brake wire is tapped. Done means the bracket is on, both heads are wired and synced, and brake pop works in the truck.

## Constraints

- **No drilling.** The bracket's long piece goes on with the existing rear plate screws.
- **No brake wire tap.** The brake is read over OBD-II with the Whelen CC5K1 CANport kit.
- **Module model matters.** Whelen's price list (PL18.1CT) lists the CANport OBD-II interface only in the CANWCT3 module, and the OBDII Communication board is optional (guide 14C81C). Brake pop depends on reading the module's label.
- **Plate legibility:** the bracket and heads must not cover any plate characters or the state name. Check the current state rule.
- **Steady burn:** SpeedTech says not to run steady burn more than an hour.

## Brake pop with the CanTrol

<Gallery photos={[{ src: cc5k1, alt: 'Whelen CC5K1 OBD-II CANport harness coiled, with the OBD-II plug, pass-through socket and white 8-pin connector, product photo.', caption: 'Whelen Carbide CanTrol OBDII CANport Kit (CC5K1 - Ford), product photo.' }]} />

1. **Brake signal in.** The CanTrol reads the brake pedal from the truck's own data bus through the CC5K1 kit. Its OBD-II plug goes into the truck's port under the dash. A pass-through OBD-II socket on short leads keeps the port free for scan tools, and the kit's male OBD-II connector mounts next to the truck's port with the supplied hardware. Its 8-position connector plugs into the OBDII Communication board inside the CanTrol module, the small 8-pin header next to the USB port (Whelen guide 14C81C p.2). Data only, no power or ground wires. Install with the truck off.
2. **Warning.** LED Output 12 on slide 2/3 drives both red (Mode 1) wires: the amber/clear pattern saved in Memory 1.
3. **Pop.** In Whelen Command, add the vehicle under CANport, select the brake signal and program LED Output 13 to turn on while the brake is pressed, only when the slide switch is on (the default; it can be set to work at all times). LED Output 13 drives both green wires, which override the warning modes, so the heads go steady red while braking.
4. **Sync (manual G-TZTBL6 p.4).** Set both heads to the same pattern, join the sync wires (grey on SpeedTech's chart, white in the manual) and join the yellows, then power off and on. For left/right alternating, also program the blues: one head's blue to +12V for about 3 s (Group A), the other's for about 5 s (Group B), then power cycle. Once synced, a tap of the joined sync wires to +12V switches to alternating, and a 2 s hold switches back.

<Callout type="unverified">
Brake pop needs a CANWCT3 module, and Whelen Command has to list Brake for the 2017 F-150 (Command added 2017 to 2019 F-150 CANport support in v1.1.2.0). My copy of the Command guide doesn't name a "brake pop" setting, so the exact menu is inferred until I see it on the laptop.
</Callout>

## Bench test on 12V before mounting

1. SUPERNIGHT 12V supply, 3A fuse in a Nilight in-line holder on the feed. Black to supply −. The manual's bench test is red and black only.
2. Red to +: the warning pattern runs. Touch yellow to + to step patterns and stop on the one wanted. Holding yellow 2 s toggles steady burn (don't run steady over 1 hour) and 3 s toggles auto-cycle (manual G-TZTBL6 p.7). Power off and on to confirm Memory 1 keeps it.
3. With red on, add green to +: the head should go red. Record the draw on red and on green (meter in series).
4. Both heads on the same pattern, sync wires joined and yellows joined, power cycled: confirm they flash together.
5. Write the draws and the pattern here. Two heads at under 0.5A each use well under 1A of the 2.5A LED output.

## Changes to the install config

| Row | Before | Now |
| --- | --- | --- |
| LED Output 12 (2.5A) | Spare | Both Z-6 red (Mode 1), slide 2/3 |
| LED Output 13 (2.5A) | Spare | Both Z-6 green (red brake). Brake pop from the brake read over OBD-II |
| CANport | Unused | CC5K1 kit to the truck OBD-II port (brake status) |
| Rear loom | T1 + T2 | Adds M1 and M2 to the same run to the rear bumper |

Red to the rear is normal for brake lights, and steady red on braking matches the truck's own lamps (general knowledge). Flashing amber/clear on a private vehicle is restricted in many states, as for the other warning lights.

- **Parts:** 2x SpeedTech Lights Super Takedown (Secondary Clear) Z-6 TIR LED Surface Mount Warning Light Head (Dual Memory), Amber Clear, $119.98 for two, plus one Q-LPB bracket, $19.99 (my cart, 18 Oct).
- **Mounting:** the bracket's long piece goes on with the front vanity plate's own screws; one head on each short side piece, cable through the foam pad and the center hole (manual G-TZTSTD6 p.6). No drilling. Check that the heads clear the grille guard and the tow hooks, and stay clear of the headlamps and the guard lights.
- **Specs:** 12V DC, under 0.5A each, 1 ft cable, 24 patterns. Sync and pattern steps as above. Ask SpeedTech for the Super Takedown sheet when ordering.
- **How it works:** slide 2/3 runs the amber/clear pattern on both front heads with the rear heads. The TAKE DOWN button (spare on the 21-button head) turns both to steady white for lighting what's ahead when stopped. Steady white to the front is generally allowed only within headlamp and auxiliary lamp rules, so use takedown only when stopped (general knowledge).
