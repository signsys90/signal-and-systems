## Goal

Flash the truck's own headlamps, fogs, turn signals, brake and reverse lamps from the control head, without splicing into factory lamp wiring. Done means the EFM is on voltage input, both trigger wires come from the CanTrol, every tab is configured and tested, and brake, turn and reverse still work normally.

## Constraints

- **No splices into factory lamp or BCM wiring.** The EFM plugs inline at the BCM connectors.
- **Can't be bench-tested.** It only works plugged into the truck's BCM, so it's tested on the truck.
- **Battery off** before unplugging BCM connectors.
- **Don't guess at BCM wiring.** Only the EFM's own plug-in harness and its documented trigger inputs are used.
- **It flashes but can't hold lamps steady.** The factory high beams are the steady white from the factory lamps.

## Factory lamps on this truck

Low and high beam, front turn, fog (present on the Lariat), front LED accent (only with LED signature headlamps), rear turn, stop, center brake, reverse and bed lamp. The truck has halogen headlamp housings, so the EFM's "Front LED Accent" box does nothing (confirmed 8 Oct).

**Leak check:** the EFM inputs accept any 5 to 17V signal, so a leaking LED output could look "on" to it. With everything off, read LED Outputs 4 and 5 and expect under 1V, then check again in the truck with the EFM connected. The steps are in the [bench test plan](/projects/f150-upfit/cantrol-bench-test/).

## STE configuration (utility v3.36)

| Tab | Trigger | Lamps checked (left and right) | Pattern |
| --- | --- | --- | --- |
| Switch 1 | White wire, slide 3 (LED Output 4) | Low beam, high beam, fog, front turn, front LED accent | TBD |
| Switch 2 | Green wire, blank button 1 latched (LED Output 5) | Rear turn, brake, center brake, reverse, truck bed | TBD |
| Switch 3 (enable) | Virtual: Switch 1 and 2 both active | All ten lamps | TBD |
| Integrated switch | Double-pull high beams | High beam, fog | TBD |
| Park | Leave disabled unless wanted | — | — |

**Settings notes:**

- Use the same pattern number on every tab.
- Unlisted lamps (rear accent, mirror, trailer, trailer reverse, park, low beam #2, brake #2) likely do nothing on this truck. Leave them checked, test, and uncheck anything unwanted.
- "Disable low beam flashing when low beams active" is checked on Switch 1, 2, 3 and Integrated; the high-beam equivalent is unchecked.
- Dash Indicator and Module Status Lights are checked.
- "Disable Reverse Lamp Flashing When Braking": check it, then test.
- Switch 3 is off by default: tick Enable Switch 3.
- Save Configuration to Module, then re-open each tab to confirm.

## What each control does

| Control | Result |
| --- | --- |
| Slide 3 | Front factory lamps flash (Input 1) |
| Blank button 1 | Rear factory lamps flash (Input 2) |
| Slide 3 + blank button 1 | All factory lamps flash (Switch 3) |
| Double-pull high beams, everything else off | High beams and fogs flash (integrated switch) |

## Install steps (phase 3)

1. Done 8 Oct: the module is installed inline at BCM J3 and J7.
2. Switch it to voltage input: fit the Voltage Input Harness.
3. White to the LED Output 4 wire, green to the LED Output 5 wire.
4. Battery on; program with the STE utility; test white, green, both, and double-pull; confirm brake, turn and reverse still work.

## Troubleshooting

| Symptom | Likely cause and fix |
| --- | --- |
| Shows all-lights with only slide 3 | Input 2 also getting voltage. Check LED Output 5, and that LED Output 4 isn't tied to green |
| Does nothing | White/green not seeing 5–17V, module not seated at J3/J7, a fuse, or not configured |
| Factory lights flash oddly or fail | Headlamp, brake or turn overrides not on. Re-seat J3/J7 |
| Blank button 1 releases the lamps when let go | The button is still momentary. Set it to latch |

## Open items

- Buy the Voltage Input Harness ($15).
- Set the pattern numbers on every tab.
- When programming the CanTrol, check whether blank button 1 is still latched after a restart.
