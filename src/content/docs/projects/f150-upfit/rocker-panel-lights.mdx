## Goal

Side warning lighting low on both sides of the truck, synced to each other, coming on in slide position 3. Done means both bars are mounted on the sills, fused by measured draw, switched through the relay, and synced.

## Constraints

- **Draw not listed.** UBL's manual gives no fuse size or current draw. Each bar is measured on the bench before its fuse and wire are chosen.
- **Airbags:** UBL warns against mounting or routing in airbag deployment areas. These stay low on the sills, clear of them.
- **LED outputs are 2.5A**, so the bars can't run straight from LED Output 3. A relay carries the load; LED Output 3 only drives the coil.
- **Ground:** steel frame rail or Ford ground point. Never the battery negative post.

## Wire functions

| Wire | Function | Plan |
| --- | --- | --- |
| Red | Mode 1 | Relay pin 87 (fused feed). Fuse each bar |
| Black | Ground | Frame rail ground |
| White | Mode 2, overrides Mode 1 | Capped |
| Blue + green | Arrows | Tied together for a center-out arrow, or both capped |
| Yellow | Color/pattern select | Momentary +12V: under 1 s = color, 2 s = pattern |

## Relay

| Pin | Connects to |
| --- | --- |
| 30 | Fused battery feed from the accessory fuse block (30A) |
| 87 | Both bars' red wires, each through its own fuse |
| 86 | LED Output 3 (slide 3) |
| 85 | Ground |

The coil draws about 0.15A, well inside the LED output's 2.5A (general knowledge). A relay with a built-in suppression diode is good practice on an electronic output (general knowledge).

## Sync steps (UBL manual)

1. Set both bars to steady burn.
2. Advance only one bar one pattern with its yellow wire.
3. Turn both off and connect the two yellow wires together.
4. Turn both on. To change patterns, advance twice so one bar is on P1 and the other on P2.
5. Dual color: +12V to yellow for 2 s, release, repeat until dual color (one bar P1, the other P2).

These match the UBL Tailgate Bar Instructions, version A.4 (SKU UBL-TGB), which I checked on 8 October.

## Option: drop the relay

If both bars together draw under about 8A, they can run straight from J1-7 (a spare 10A output) with no relay. The [five-modes plan](/projects/f150-upfit/five-modes-plan/) takes this further (decision C): red on J1-7 and white on J1-8, so the CanTrol can flash them. A mechanical relay can't switch at flash rate for long, so flashing modes need the relay removed. All of this depends on the measured draw.

## 31 October update: two relays and CanTrol wiring as approved

On 31 Oct 2026 I approved the final rocker wiring (project document sections 3.1 and 9.2 G). It is now in [Upfit Studio](/projects/upfit-studio/) and on the generated [output plan](/projects/f150-upfit/cantrol-output-plan/). It replaces the single relay, the capped white, blue and green wires, and the in-cab yellow button above. The relay, wiring and option sections above are kept as the earlier plan.

### Relays (two 30A SPDT, ISO style)

| Relay | Coil trigger (pin 86) | Load (pin 87) | When it is on |
| --- | --- | --- | --- |
| A | LED Output 3 (J4-5, orange) | Both bars' red (Mode 1), each bar fused | Slides 2 and 3 |
| B | J1 Output 7 | Both bars' white (Mode 2, overrides Mode 1), each bar fused | Slide 3 |

Pin 30 on each relay is a fused battery feed and pin 85 goes to ground, as before. Fuse sizes per bar still wait on the measured draw.

### Bar wires

| Wire | Function | Goes to |
| --- | --- | --- |
| Red | Mode 1 | Relay A pin 87 (fuse each bar) |
| White | Mode 2 (overrides Mode 1) | Relay B pin 87 (fuse each bar) |
| Blue (both bars joined) | Left arrow | LED Output 22: left-arrow and both-arrows keys |
| Green (both bars joined) | Right arrow | LED Output 23: right-arrow and both-arrows keys. Blue and green together = center out |
| Yellow (both bars joined) | Pattern / color step | LED Output 32: LEFT ALLEY key, momentary (under 1 s = color, 2 s = pattern) |
| Black | Ground | Bare chassis ground (frame rail or Ford ground point, never battery negative) |

- The yellow pattern step moves from a separate cab button to the LEFT ALLEY key on the control head.
- The arrow wires are now used, so the rockers join the arrow keys with the Color Flood bar. Rocker arrow behavior is marked "BENCH" in the plan.
- Status: bars and relays still to buy; nothing bench-tested or programmed.

## Bench test

Measure the draw steady and flashing, size the fuse and wire, and practice the sync steps, all before mounting.

## Troubleshooting

| Symptom | Likely cause and fix |
| --- | --- |
| Off in slide position 3 | Relay coil not getting LED Output 3, pin 85 open, or a bar's black not grounded |
| Won't sync | Not both on steady burn before joining the yellows, yellows not joined, or not advanced twice for P1/P2 |
