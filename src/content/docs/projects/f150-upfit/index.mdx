## Goal

Build a clean, serviceable emergency lighting and siren package on a daily-driven truck, with every circuit fused, documented and controllable from one control head. Done means every component is installed, bench-tested on 12V before any drilling, verified in the vehicle, and documented on its own component page.

## Constraints

- **Vehicle:** 2017 Ford F-150 Lariat SuperCrew.
- **Roof:** panoramic roof, so no overhead or roof-mounted equipment. Interior lighting mounts at the visor line.
- **Rear glass:** power sliding rear window, which limits rear-glass mounting.
- **Factory electrical:** the factory lamps are flashed through the BCM by the SpeedTurtle EFM 3.0. No guesswork on BCM or factory wiring.
- **Airbags:** all mounting and wire routing stays clear of airbag deployment zones.
- **Controller:** one Whelen CanTrol WC Gen 3 with the 21-button control head. It replaced an earlier plan for a CenCom Sapphire.

## Build steps

1. Bench test every device on 12V before drilling or routing wire.
2. Install the AGM battery and the main fused feeds near the battery.
3. Mount the control head and controller, then route the harness through grommets and loom.
4. Install and wire each lighting device, one component page per device.
5. Install the siren speakers and configure the siren amp.
6. Program the CanTrol button layout and patterns.
7. Verify every function in the vehicle and update each component's status.

## Safety notes

- Fuse every feed as close to the battery as practical.
- Use grommets at every panel or firewall pass-through, and loom on every run.
- Keep mounts and wiring clear of airbag zones, including the A-pillars, headliner curtain airbags and visor area.
- Do not tap or modify BCM or factory wiring based on guesses. Use the device manufacturer's documented method only.
- Bench test on 12V before drilling.
