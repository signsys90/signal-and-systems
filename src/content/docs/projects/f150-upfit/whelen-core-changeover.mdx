The Federal Signal SLB-FRD15ND no-drill bracket kit, bought for the E68Xtreme's headliner mount, is not needed now that the stick goes on the headrest brackets. It's new in an opened bag and will be sold.

## What this means for the rest of the build

- **Controller.** The new controller is a Whelen CenCom Core, model C399 (my note, 23 Nov; specs still to add from Whelen's documents). The CanTrol WC set isn't for sale yet. The CanTrol output plan, bench files and CANport setup were built for the CanTrol, so the Core needs a new output plan and new programming. Until that plan is written, the CanTrol pages stay as the record of the earlier build.
- **CANport.** The CC5K1 was the CanTrol's OBD-II interface for the eight CAN vehicle inputs set up on 31 Oct. Its replacement is the Core's OBD-II cable, so the CANport setup will change. Per my rule, that change goes on both these F-150 pages and the [Upfit Studio](/projects/upfit-studio/) page.
- **Other planned lights.** The HELLA heads and the UBL Mini-X pair will likely carry over to the Core. They, the E68Xtreme and the LUMENIX bars were all assigned to CanTrol outputs and need new assignments on the Core.
