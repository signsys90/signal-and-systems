## Goal

Give responders a fast, offline way to read the PDF417 barcode on a driver license or state ID and see the AAMVA fields on screen, without the data ever leaving the device unless the operator chooses to export it.

## Constraints

- **Hardware:** Panasonic Toughbook CF-33 running Windows.
- **Offline only:** no network services and no telemetry.
- **Privacy:** no automatic persistence of personal information. Exports are explicit and operator-initiated.
- **Stability:** changes are small and isolated, with regression tests and release candidates, so the stable core is never broken.

## Privacy statement

The Responder ID Scanner does not store scanned personal information automatically, does not send telemetry, and does not open network connections. Data leaves the app only when the operator explicitly exports it. All screenshots and examples on this site use synthetic sample IDs, never a real license or a real person.

## Build steps

1. Set up the Python environment and install dependencies.
2. Run the pytest suite.
3. Build the Windows executable with PyInstaller.
4. Install the release candidate on the CF-33 and test with synthetic IDs.
